# مرصاد | MERSAD

**نرصد اليوم، نتوقع الغد.**

منصة ذكية تفاعلية لتحليل أنماط الجرائم في المدن وتحويل البيانات إلى قرارات قابلة للتنفيذ.
مبنية على عينة تحليلية (١٠٠ ألف حادثة) من بيانات جرائم شيكاغو العامة المنظّفة، وموديل
XGBoost مدرَّب فعليًا ضمن مشروع مرصاد (دقة ~87% على بيانات الاختبار).

## التشغيل محليًا

```bash
pip install -r requirements.txt
streamlit run app.py
```

سيفتح التطبيق تلقائيًا على `http://localhost:8501`.

**ملاحظة على أسماء الملفات:** كل ملفات الكود بأسماء إنجليزية ASCII بالكامل (بدون عربي أو
إيموجي بمسار الملف) لتفادي مشاكل الترميز الشائعة عند الرفع لـGitHub / Streamlit Cloud.
العناوين والأيقونات المعروضة فعليًا بالتطبيق (بالشريط الجانبي وبكل صفحة) عربية بالكامل،
ومحدّدة صراحة عبر `st.Page(..., title="...", icon="...")` بملف `app.py`.


## ملاحظات مهمة

- **لا بيانات مختلَقة**: كل رقم بالتطبيق (الإحداثيات، أنواع الجرائم، مستويات الخطورة،
  التوصيات) مشتق من `data/mersad_sample.csv` مباشرة أو من موديل XGBoost المدرَّب.
- **Risk Score للمناطق**: مؤشر مركّب (0–100) مبني على نسبة الحوادث عالية الخطورة
  تاريخيًا + الكثافة النسبية لعدد الحوادث بكل منطقة (`utils/data_processing.py`).
- **تقييم الخطورة (صفحة 3)**: يستخدم موديل XGBoost نفسه المدرَّب بالنوت بوك — تقدير
  إحصائي لمستوى الخطورة، وليس تنبؤًا بجريمة فردية.
- **تخطيط الموارد**: نموذج أولي (Prototype) لتوضيح فكرة التوزيع الذكي، والأرقام
  افتراضية للتوضيح فقط.
- **قابلية التوسّع**: لتحديث البيانات بمجموعة أكبر أو أحدث، استبدلي
  `data/mersad_sample.csv` بنفس بنية الأعمدة، وأعيدي تدريب/حفظ الموديل بنفس
  `feature_cols.joblib` لضمان التوافق.

## المصدر

City of Chicago — Crimes 2001 to Present (Chicago Data Portal), معالج ومنظّف ضمن
مشروع مرصاد باستخدام RAPIDS (cuDF / cuML) وXGBoost.
